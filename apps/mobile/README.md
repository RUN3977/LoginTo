# LoginTo Mobile And Tablet Terminal App

Planned target: React Native / Expo Dev Client.

The mobile/tablet app handles:

- Fast vault lookup.
- Biometric unlock.
- Camera capture.
- Local OCR-assisted record drafts.
- Local reminders and notifications.
- QR pairing with desktop, tablet, or backup devices.
- Hotspot/local-network sync.

Tablet support should reuse the mobile codebase while improving list/detail,
attachment review, and batch confirmation layouts.
