# LoginTo Desktop Terminal App

Planned target: Tauri + React + TypeScript.

The desktop app is the most capable local terminal:

- Local encrypted vault access.
- Tray and quick search.
- Local reminders and system notifications.
- Attachment browsing and bulk organization.
- Local network sync service.
- QR pairing support for mobile and tablet terminals.
- Encrypted sync package import/export.

This directory intentionally does not contain a Web/PWA app. React is only the
planned UI technology inside a native local terminal app.
