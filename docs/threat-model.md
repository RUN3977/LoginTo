# LoginTo Threat Model

版本：M0 / 终端设备版

## 保护对象

- 社交账号、网站账号、邮箱、密码、2FA 备用码。
- 银行卡、会员卡、证件、API Key、Recovery Code。
- 照片附件、证件照片、卡片照片。
- 提醒规则、备注、标签、同步历史。
- 设备身份密钥和保险库密钥材料。

## 明确不保护的范围

- 用户主动导出的明文文件。
- 用户主动复制到其他软件后的内容。
- 已被操作系统或恶意软件完全控制的设备。
- 用户遗忘主密码且没有恢复包的情况。

## 主要威胁与缓解

| 威胁 | 风险 | MVP 缓解 |
|---|---|---|
| 设备丢失 | 本地保险库被离线攻击 | 主密码派生密钥、保险库密钥包裹、自动锁定、敏感字段隐藏 |
| 导出泄露 | 备份包或同步包被截获 | 只导出加密包，导出前二次确认，包内带版本和校验 |
| 剪贴板泄露 | 密码或卡号被其他软件读取 | 复制后自动清除，可配置清除时间，高敏字段二次验证 |
| 同步中间人 | 攻击者冒充设备 | 扫码配对、公钥交换、6 位验证码面对面核对 |
| 同步冲突覆盖 | 重要字段被误覆盖 | 冲突保留双方版本，进入待合并列表 |
| OCR 误识别 | 错误字段进入保险库 | OCR 只生成草稿，用户确认后才入库 |
| 云端泄露 | 数据上传后不可控 | MVP 不做公共云登录、云存储、云 OCR |
| 附件泄露 | 证件照片或卡片照片暴露 | 附件独立加密 blob 保存，元数据不包含敏感明文 |
| 主密码遗忘 | 用户无法恢复保险库 | MVP 提供加密备份说明，后续支持紧急恢复包 |

## 敏感级别

| 级别 | 说明 | 示例 | UI 行为 |
|---|---|---|---|
| `public` | 可以显示和搜索的普通信息 | 标题、分类、标签 | 默认显示 |
| `private` | 用户私密但非最高风险信息 | 用户名、绑定邮箱、会员号 | 可显示，可选隐藏 |
| `secret` | 泄露后可能造成直接损失 | 密码、API Secret、证件号、银行卡号 | 默认隐藏，复制后清剪贴板 |
| `critical` | 高风险字段或用户强制保存的极敏信息 | 2FA 备用码、银行卡 CVV、恢复码 | 默认隐藏，建议二次验证 |

## 安全默认值

- 新建记录时，密码、卡号、证件号、密钥字段默认为 `secret`。
- CVV 不作为银行卡模板默认字段。
- OCR 文本不进入可搜索明文索引，除非用户确认保存为普通备注。
- 同步前必须展示对方设备名称和验证码。
- 加密备份导出需要显示风险提示。

## 后续安全任务

- 将当前 WebCrypto AES-GCM + PBKDF2 fallback 升级或并行为 Argon2id/XChaCha20-Poly1305 原生适配器，并完成参数审计。
- 明确 Argon2id 参数基线。
- 明确 XChaCha20-Poly1305 nonce 和 key rotation 策略。
- 明确系统安全存储适配：Windows Credential Manager、macOS Keychain、Android Keystore、iOS Keychain。
- 添加恶意附件处理策略。
- 添加恢复包设计。
